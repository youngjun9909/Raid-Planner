# 설계 수정: 숙련도 (2026-10-16)

`2026-10-16-multi-run-planning-amendment.md`(여러 공대 편성) 위에 얹는 기능이다. 사용자가 정한 것과 설계자의 결정을 구분해 적는다.

## 사용자가 정한 것
- 숙련도는 세 단계: **숙련**(가장 높음) > **반숙**(중간) > **클경**(가장 미숙). 값은 이 한글 이름 그대로 보여 준다.
- **캐릭터마다, 레이드 이름마다** 정한다 (난이도와 무관: 세르카는 노말이든 하드든 같은 숙련도).
- 캐릭터 정보를 갱신(로스터 새로고침, 주간 크론)해도 유지된다.
- 정하지 않은 칸의 기본값은 **반숙**.
- 추천에 반영한다. 반영 방식(아래)을 사용자가 확인했다.
- 디스코드에서도 정할 수 있어야 한다 (`/숙련도`).

## 추천에 반영하는 규칙
편성 계산(`planRaid`)이 각 대상 캐릭터의 그 레이드 숙련도를 알고 있어야 한다.
1. 공대마다 **숙련자(숙련)가 최소 한 명** 들어가도록 우선한다. 숙련자가 전체에 모자라면 가능한 한 고르게 퍼뜨린다.
2. **클경은 공대마다 한 명 이하**가 되도록 나눈다. 클경이 공대 수보다 많으면 한 공대에 둘 이상 들어갈 수 있다 (막지는 않는다).
3. 후보 순위: 외부 서포터 수 적은 순 → 외부 총 인원 적은 순 → 가장 나쁜 단계(위험>빠듯함>모름>여유) → **숙련도 균형** → 공대 간 전투력 평균 차이. 숙련도 균형은 다음 값으로 비교한다: (a) 숙련자 없는 공대의 수(적을수록 좋음), (b) 클경이 2명 이상인 공대의 수(적을수록 좋음), (c) 공대별 숙련도 점수(숙련=3, 반숙=2, 클경=1의 합)의 최대−최소(작을수록 좋음).
4. 전투력 단계(여유/빠듯함/위험/모름)와 권장 전투력 계산은 그대로 둔다. 숙련도는 단계를 바꾸지 않고 따로 보여 준다.
5. 외부 자리의 숙련도는 알 수 없으므로 숙련도 계산에서 제외한다 (숙련자 없는 공대 판단에서 외부 자리는 숙련자로 세지 않는다).
6. 공대에 숙련자가 없고 그 레이드에서 숙련자를 넣을 수 있는 방법이 없으면 경고 표시만 한다(후보를 막지 않는다).

## 저장과 API
- 저장소에 `prof:<friendId>` 해시(필드: `<캐릭터명>|<레이드 이름>` → `숙련|반숙|클경`)를 둔다. 기존 수동 전투력/역할 덮어쓰기와 같은 방식(`listFriends`/`getFriend`가 합쳐서 돌려주는 방식 또는 별도 조회)으로 `Store`에 `setProficiency(friendId, characterName, raidName, level | null)`을 둔다. `null`이면 기본값(반숙)으로 돌아간다. `deleteFriend`는 이 해시도 지운다. 메모리/Upstash 두 구현이 같은 결과를 내야 한다 (기존 계약 테스트 방식).
- 웹 API: `PUT /api/friends/[id]/proficiency` body `{characterName, raidName, level}` (level은 `숙련`/`반숙`/`클경`/null; 모르는 레이드 이름이나 이 친구의 캐릭터가 아니면 400, 친구가 없으면 404). 비밀번호 검사는 다른 경로와 같다.
- `Character` 타입에 레이드별 숙련도를 직접 넣기보다, 편성 입력에 `proficiency(friendId, characterName, raidName) → level`을 주는 방식을 쓴다 (설계는 빌더 재량이지만 기본값 반숙, 로스터 갱신 후 유지, 타입 안전을 지킨다).

## 화면
- 클리어 표의 레이드 칸(캐릭터 × 레이드 이름)에 클리어 드롭다운 옆/아래로 작은 숙련도 선택(숙련/반숙/클경)을 둔다. 기본값(반숙)은 흐리게, 직접 정한 값은 또렷하게 보여 준다. 색에만 의존하지 않고 글자도 같이 쓴다. 모바일에서도 표가 망가지지 않게 한다 (표는 자체 가로 스크롤).
- 추천 카드의 공대 안 구성원 줄에 숙련도 배지(글자 + 아이콘/모양)를 붙인다. 공대 제목 옆에 `숙련 1 · 반숙 1 · 클경 0` 요약. 숙련자가 없는 공대에는 "숙련자 없음" 경고 문구(색+아이콘+글자).
- 디스코드: `/숙련도` 명령어(옵션: 캐릭터, 레이드, 숙련도 — 숙련도는 선택지 3개, 레이드는 레이드 이름 6개 선택지, 캐릭터는 내 캐릭터 중에서 고르는 방식(자동완성 또는 선택 메뉴))와 `/명령어` 도움말 갱신, 추천 임베드의 구성원 줄과 공대 칸 제목에 숙련도 표시. 본인 캐릭터만 바꿀 수 있다 (기존 `/클리어`와 같은 권한 규칙).
- 한글 문구: 명령어 설명과 모든 노출 텍스트는 한국어.

## 성능
숙련도 때문에 편성 계산이 느려지면 안 된다 (8명 × 캐릭터 6개 < 1초, 16명 × 6개 < 3초 유지).
