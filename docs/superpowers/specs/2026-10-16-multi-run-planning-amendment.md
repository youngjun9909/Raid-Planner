# 설계 수정: 여러 공대로 나뉘는 편성 (2026-10-16)

원 설계(`2026-10-16-raid-party-planner-design.md`)는 "한 사람은 한 레이드에서 캐릭터 하나만 골라 한 공대에만 들어간다"로 편성했다. 실제로는 한 사람이 같은 레이드를 **캐릭터마다 한 번씩** 갈 수 있어서, 갈 수 있는 캐릭터가 둘인 사람의 나머지 캐릭터가 편성에서 빠졌다. 사용자가 실제 화면(영준: 캐릭터 1개, 현준: 캐릭터 2개)으로 지적한 문제다. 이 문서는 원 설계와 충돌하는 부분만 덮어쓴다 (나머지는 그대로).

## 사용자가 정한 것
- 한 캐릭터는 한 번만 쓰인다. 영준의 갈 수 있는 캐릭터가 1공대에 쓰였으면 2공대에는 나올 수 없다.
- 같은 공대 안에 같은 사람이 둘 들어갈 수 없다 (원 설계 유지).
- 같은 사람이 **다른 공대에 다른 캐릭터로** 들어가는 것은 된다 (현준이 2개면 두 공대에 하나씩).
- 화면: **추천 1, 추천 2, …** 가 세로로 쌓이고, 각 추천 안에 1공대, 2공대, …가 들어간다. "분배"라는 말은 쓰지 않는다. 같은 캐릭터는 한 추천 안에서 한 번만 나온다.

## 새 편성 규칙 (설계자의 결정; 사용자가 틀리면 고친다)
레이드 하나에 대해:
1. **대상 캐릭터**: 참석한 친구들의 캐릭터 중 입장 레벨이 되고 이번 주에 그 레이드(어느 난이도든)를 아직 안 간 캐릭터 전부. 갈 수 있는 캐릭터가 하나도 없는 친구는 `excluded`(사유 "가능한 캐릭터 없음").
2. **기본 목표**: 대상 캐릭터를 **모두 한 번씩** 어느 공대엔가 넣는다. (안 갈 캐릭터는 클리어 표에서 '갔음'으로 표시해 빼는 방식. 사용자가 이 가정을 아직 확인하지 않았으므로 요약에 "캐릭터 N개 편성"을 보여 줘서 바로 눈에 띄게 한다.)
3. **공대 하나의 구성**: 공대 인원은 항상 `raid.size`. 친구 캐릭터는 같은 사람 중복 없이, 서포터는 서포터 자리(`size/4`)를 넘지 않고, 딜러는 `size − 서포터 자리`를 넘지 않는다. 모자란 자리는 외부 서포터(서포터 자리가 비면), 나머지는 외부 딜러로 채운다. 외부인은 평균 전투력에서 제외.
4. **공대 수 `P`**: 위 제약을 만족하는 **최소** 수. 최소 `P ≥ max(친구별 대상 캐릭터 수)`, `P ≥ ceil(딜러 수 / (size−서포터 자리))`, `P ≥ ceil(서포터 수 / 서포터 자리)`, `P ≥ ceil(캐릭터 수 / size)`. 최소 `P`로 배정이 안 되면 `P+1`까지 시도한다.
5. **여러 추천**: 서로 다른 배정을 여러 개 만들어 순위를 매겨 상위 몇 개(기본 3)를 돌려준다. 순위: 외부 서포터 수 적은 순 → 외부 총 인원 적은 순 → 가장 나쁜 단계(위험>빠듯함>모름>여유) → 공대 간 평균 전투력 차이가 작은 순. 같은 배정(공대 안 구성이 같고 공대 순서만 다른 것)은 중복으로 보고 하나만 남긴다.
6. **단계(여유/빠듯함/위험/모름)** 와 권장 전투력 비교는 원 설계 그대로 (공대별 딜러 평균).
7. 후보가 아예 없는 경우의 `reason`은 그대로 둔다.

## 성능
참석 8명 × 캐릭터 6개(최대 48캐릭터)에서 1초 안에 끝나야 한다. 완전 탐색이 아니라 결정적(같은 입력은 같은 결과) 휴리스틱(그리디 + 교환 개선, 고정 시드 가능)으로 한다. 16명 규모에서도 수 초를 넘기지 않아야 한다 (기존 P+1 재시도 폭주 문제를 반복하지 않는다).

## 화면 문구
- 카드 제목: `추천 1`, `추천 2`, … (첫 번째에 ⭐). "분배" 삭제.
- 카드 맨 위 요약 한 줄: `친구 N명 · 캐릭터 M개 · 공대 P개 · 외부 E명 필요(서포터 a, 딜러 b)`.
- 카드 안에서 공대는 `1공대`, `2공대`, …로 세로로 쌓는다 (추천 카드끼리도 세로로 쌓는다. 나란히 두지 않는다).
- 공대 안 구성원 줄에는 친구 이름, 캐릭터, 역할, 아이템 레벨, 전투력을 보여 준다 (기존 유지). 같은 친구가 다른 공대에 나오면 이름은 그대로 나온다.
- 디스코드는 추천마다 임베드 하나, 공대마다 칸 하나. 제목 `추천 1 · <레이드 이름 난이도>`.
